HIMARPL memelihara beberapa proyek _open-source_ yang dapat dikontribusikan oleh siapa saja:

- [devoria-himarpl](https://github.com/himarplupi/devoria-himarpl) - Situs web utama kabinet HIMARPL saat ini
- [mabim-himarpl](https://github.com/himarplupi/mabim-himarpl-2025) - Situs Web Masa Bimbingan Rekayasa Perangkat Lunak Periode 2025
- [docs-himarpl](https://github.com/himarplupi/docs-himarpl) - Dokumentasi Teknis HIMARPL (situs web ini)
