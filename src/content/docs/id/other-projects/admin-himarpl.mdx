Admin panel HIMARPL tersedia di [admin.himarpl.org](https://admin.himarpl.org) dengan role admin. Dibuat dengan NextJS, platform ini dapat diakses secara eksklusif oleh anggota HIMARPL melalui _private repository_.

:::note[Staff Baru]
  Mohon untuk mengecek [staff guide](/getting-started/04-staff-guide) sebelum memulai.
:::

## Fitur Inti

Admin panel kami menawarkan empat fungsi utama:
- Manajemen member: Menambah, memperbarui, dan mengawasi keanggotaan HIMARPL
- Administrasi Departemen: Menangani struktur organisasi HIMARPL
- Manajemen News: Menambah, memperbarui, menghapus, dan mengawasi News HIMARPL
- _Dashboard_ analitik: Melacak aktivitas user secara _real-time_ dan memonitor tren konten yang dibuat
