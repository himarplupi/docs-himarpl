[himarpl.org](https://devoria.himarpl.org) is the official website for Devori Cabinet, Himpunan Mahasiswa Rekayasa Perangkat Lunak (HIMARPL) at The Education University of Indonesia. The website is built using React with the T3 Stack and is deployed on Vercel.

## Key Features

- News & Updates Integration
- Organization Structure Visualization
- Department Information Pages
- Interactive UI Components
- Responsive Design
- Smooth Animations

## Libraries Used

**Core Dependencies**
  - React (19.1.0)
  - React DOM (19.1.0)
  - TypeScript (^5.9.3)

**Database & API**
  - Prisma (@prisma/client ^5.22.0)
  - Axios (^1.9.0)

**UI & Styling**
  - Radix UI Components (various @radix-ui/* packages)
  - Tailwind CSS (^4.1.5)
  - Motion (^12.18.1)

**Development Tools**
  - ESLint (^9.22.0)
  - Prettier (^3.2.5)
  - Various ESLint plugins and configurations
